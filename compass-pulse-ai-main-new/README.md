# Compass Pulse AI

## Prerequisites

### Install Bun

**Windows (PowerShell):**
```powershell
irm bun.sh/install.ps1 | iex
```

Restart your terminal after installation, then verify:
```powershell
C:\Users\valenciatayje\.bun\bin\bun.exe --version
```

## Getting Started

Install dependencies:
```powershell
C:\Users\valenciatayje\.bun\bin\bun.exe install
```

Start the development server:
```powershell
C:\Users\valenciatayje\.bun\bin\bun.exe run dev
```

The app will be available at `http://localhost:8080`.

Build for production:
```powershell
bun run build
```
